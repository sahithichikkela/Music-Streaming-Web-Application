# Music-Streaming-Web-Application
## Introduction
The MERN stack—comprising MongoDB, Express.js, React.js, and Node.js—is a widely used technology stack for developing modern full-stack web applications. Thanks to the rapid growth and evolution of the JavaScript ecosystem, MERN has become one of the most preferred stacks among developers. Its simplicity, flexibility, and ease of setup make it especially suitable for beginners as well as experienced developers.

Music-Streaming-Web-Application is a complete full-stack music streaming platform that can be quickly set up and deployed. The frontend is developed using React.js, styled with Tailwind CSS, and enhanced with animations using Framer Motion. The backend is powered by Node.js, Express.js, MongoDB, and Mongoose for efficient database management.
 

## Music-Streaming-Web-Application
A web-based music streaming player similar to YouTube Music, built using the MERN stack.

The application includes features such as displaying song lyrics, album information, artist details, and advanced search functionality with filters.

It has functionality like specific lyrics, album details, artist details, searching using filters.
## Features
This application offers the following functionalities:

-User authentication using JWT (JSON Web Token).
-Stream songs and explore albums and artist information.
-Search for songs, albums, and artists using filters.
-View song lyrics in real-time while listening.
-Direct link to the artist’s Instagram profile.
-Access to predefined playlists.
